# DATN
1. Hướng dẫn sử dụng
Các bước vận hành mô hình hệ thống phân loại sản phẩm theo màu sắc
sử dụng STM32:
Bước 1: Cung cấp nguồn cho mô hình bằng cách cắm nguồn 12V được
cung cấp qua adapter lấy nguồn từ điện dân dụng 220V.
Bước 2: Điều khiển trạng thái hoạt động.
Trên mạch có 4 nút nhấn gồm:
Nút nhấn 1: Bắt đầu chương trình hệ thống.
Nút nhấn 2: Tạm dừng chương trình hệ thống.
Nút nhấn 3: Tăng tốc độ bàn quay phân loại sản phẩm.
Nút nhấn 4: Giảm tốc độ bàn quay phân loại sản phẩm.
